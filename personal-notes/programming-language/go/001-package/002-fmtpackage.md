# `fmt` package

- `fmt` stands for "format"
- contain standard functionality of Input and Output in Go program.

`fmt` package is standard for Go program to printing output to console, read
user input and formatting strings. `fmt` package provides various functionality
to manipulate and formatting string.

Some functionality provided by `fmt` include:

| Function Name | Functionality                                    |
| ------------- | ------------------------------------------------ |
| `Print`       | Print value to console                           |
| `Printf`      | Format and print values to the console           |
| `Println`     | Print value to the console, followed by new line |
| `Scan`        | Read input from user                             |
| `Scanf`       | Read anf Format inptu from the use               |
| `Sprintf`     | Format strings and return the resulting string   |
